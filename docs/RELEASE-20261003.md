## 升级、限制及下一步

默认 production 要求有效密钥与先迁移；固定演示账户需显式 APP_MODE=demo，管理员目录限 ADMIN。新缺陷号是 UUID 不透明字符串，旧号保留。库存有效小数超两位、负值、超范围或空数量返回 422，零转移和累计溢出返回 400，零盘点成功。数据库备份/恢复不支持含 `=` 或以 `postgres://`、`postgresql://` 开头的库名。本轮无新增 schema 或历史数据改写。

后续范围是部分收货重放幂等、状态竞争、过时绝对盘点、采购创建/自动补货边界、编号竞争及可靠外部联动。既有弃用、大包警告和依赖审计范围保留。备份不含附件、密钥和 PG 全局角色；代码回退不能恢复业务数据。模拟测试与 CI 不构成现场投运、完整离线浏览器或生产容量证明。
